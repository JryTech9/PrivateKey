Works completely offline — nothing is sent anywhere. Keep this file and your private key file on YOUR computer only.

⚠ This browser has no Ed25519 support. Use an up-to-date Chrome, Edge, Firefox or Safari (and open this file directly, not from a web page).

1 Signing key locked

One signing key for ALL your routers. The router firmware only contains the matching public key, so a router can never create keys itself.

🔐 The private key file is the only way to make activation keys. Back it up (USB + another place). If someone gets the file AND the passphrase they can issue keys; if you lose it you cannot issue new ones for firmware that holds this public key.

2 Create an Activation Key

The customer opens Admin → Maintenance → Activation License Key and sends you the Hardware ID.

Send this key to the customer. It only works on the router with this exact Hardware ID.
